# 🫧 Underwater Pomodoro App

A simple underwater-themed pomodoro app that automatically switches between work and break mode. Built with `React` + `Electron`.

<img width="428" height="322" alt="image" src="https://github.com/user-attachments/assets/d5f0b496-4756-45b9-a4e6-f7eaa59d0c80" />

## 🪸 Features
- **25/5 minute work/break timers**
- **Automatic mode switching:** Automatically switches to a next mode when timer finishes.
- **Resizable window**
- **Custom draggable title bar**
- **Custom-drawn pixel art buttons**
- **Dynamic background wallpaper:** Background switches depending on mode

## 🐠 Running the project
The fully built app for both macOS and Windows can be found in the [Releases](https://github.com/stephkmn/underwater-pomodoro/releases) tab.

1. Clone the repo
``` bash
git clone https://github.com/stephkmn/underwater-pomodoro.git
cd underwater-pomodoro
```

2. Install dependencies
```bash
npm install
```

3. Run the app in development mode
``` bash
npm run dev
```
